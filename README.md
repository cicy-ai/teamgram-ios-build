# teamgram-ios-build

GitHub Actions build of [teamgram/teamgram-ios](https://github.com/teamgram/teamgram-ios)
(`teamgram2`, Telegram 12.5, Xcode 26.2) pointed at a self-hosted teamgram-server.

Run: Actions → "teamgram-ios unsigned IPA" → Run workflow. The unsigned IPA is published
as a release asset and workflow artifact; install it with Sideloadly.
